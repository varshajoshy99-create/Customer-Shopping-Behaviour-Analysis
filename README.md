# Customer-Shopping-Behaviour-Analysis
End-to-end Data Analytics project using Python, MySQL, and Power BI. Includes data cleaning, Exploratory Data Analysis (EDA), SQL queries, interactive dashboard development, report writing, and presentation creation using Gamma to generate meaningful business insights.


# Data Analytics Project

## 📌 Project Overview

This project demonstrates an end-to-end data analytics workflow, from data preparation to business insights and visualization. Python was used for data loading, cleaning, and Exploratory Data Analysis (EDA), while MySQL was used to perform SQL queries. Power BI was used to build an interactive dashboard, and a project report and presentation were prepared using Gamma.

**Objective:** To analyze data, identify meaningful patterns, and present insights that support data-driven decision-making.

##  Dataset

- **Format:** CSV
- **Source:** Kaggle
- **Purpose:** To explore trends, compare categories, and identify meaningful insights.
- **Preprocessing:** Checked missing values, duplicates, data types, and column consistency.

## 🛠️ Tools & Technologies

- **Python:** Data analysis and preprocessing
- **Pandas:** Data manipulation and cleaning
- **SQLAlchemy**: Connected Python with MySQL using create_engine()
- **MySQL:** SQL queries and data analysis
- **Power BI:** Interactive dashboard and KPI visualization
- **Gamma:** Presentation creation
- **GitHub:** Project documentation and sharing

##  Project Steps

### Step 1: Data Loading and Exploration

- Imported the dataset using Pandas.
- Examined data structure and data types using `df.info()`.
- Generated summary statistics using `df.describe()`.

### Step 2: Data Cleaning

- Identified and handled missing values.
- Checked for duplicate records.
- Standardized column names.
- Corrected data types where necessary.

### Step 3: Exploratory Data Analysis (EDA)

- Analyzed distributions and summary statistics.
- Compared variables and categories.
- Identified patterns and trends through visualizations.

### Step 4: SQL Analysis Using MySQL

- Imported the prepared dataset into MySQL.
- Executed SQL queries using filtering, grouping, sorting, and aggregate functions.
- Analyzed key metrics to answer business questions.

### Step 5: Power BI Dashboard

- Created KPI cards and charts.
- Developed an interactive dashboard using relevant visualizations.
- Presented key metrics and findings in an accessible format.

### Step 6: Reporting and Presentation

- Prepared a report summarizing the methodology and findings.
- Created a presentation using Gamma to communicate the project workflow and key insights.



##  Results and Key Insights

Based on the data analysis, the following business recommendations were identified:

Grow the Subscriber Base: Offer exclusive benefits and incentives to encourage more customers to subscribe.

Reward Repeat Customers: Introduce loyalty programs to encourage repeat purchases and move customers into the “Loyal” segment.

Optimize Discount Strategies: Review discount policies to maintain sales growth while protecting profit margins.
